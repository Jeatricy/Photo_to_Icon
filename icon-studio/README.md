# IconLab · 照片转图标

根据参考图实现的中文网页工具。原图在浏览器中处理，无需上传照片，无需安装前端依赖。

## 本地启动

在当前目录打开 PowerShell：

```powershell
node server.mjs
```

打开 http://127.0.0.1:4173/ 。如果端口被占用，可运行 `node server.mjs 4174`。

上级目录提供「启动工具.cmd」，双击后会在本地服务启动成功时自动用默认浏览器打开工具页面。使用期间保持启动窗口打开，关闭窗口即可停止本地服务。也可运行 node server.mjs --open 自动打开网页。不要直接以 file:// 打开网页，以避免图片跨域与画布读取限制。

## 功能

- 点击、拖拽上传，多张图片批量转换；最多 20 张，每张不超过 20 MB、4000 万像素。
- 支持 JPG、PNG、GIF、WEBP、SVG、HEIC/HEIF；也可读取浏览器支持的 BMP、AVIF 和 ICO。
- 图片链接导入，支持请求超时、非图片内容、大小限制和跨域错误提示。
- 多分辨率 ICO：每张源图片生成一个包含所选尺寸的图标。
- 独立 ICO / PNG：每张图片的每个尺寸生成一个文件。
- 常用尺寸：16、24、32、48、64、72、80、96、128、256 像素。
- 自定义尺寸：宽高 16–256，支持非正方形、多个尺寸和自动去重。
- 实时主预览及 16 / 32 / 48 / 64 像素预览。
- 居中裁剪、完整保留、0–50% 圆角、透明背景与自选底色。
- 预览用透明、白色、深色背景，不改变实际导出设置。
- 输出文件列表、单个下载、ZIP 打包、重名编号、清空结果和重置。
- 中文使用指南、键盘操作和手机布局。

GIF 与动态 WEBP 导出静态第一帧。透明背景会保留原图透明度，不会自动抠图。链接来源必须允许 CORS；受限制时可先保存到本地再导入。HEIC 解码器随项目提供，首次导入按需加载。为控制批量处理内存，过大图片会先生成最长边 1024 像素的工作图，原始尺寸仍显示在文件信息中。

## 测试

```powershell
node --test tests/core.test.cjs
```

测试覆盖自定义尺寸校验、ICO 图像目录、256 尺寸表示、BGRA 顺序、透明 Alpha、AND 遮罩行对齐、CRC-32 和 UTF-8 ZIP 目录。
详细人工和独立解码验证记录见 `VALIDATION.md`。

## 文件结构

- `dist/index.html`：中文界面
- `dist/styles.css`：响应式样式
- `dist/app.js`：图片处理、预览、下载与交互
- `dist/core.js`：ICO / ZIP 编码和尺寸解析，浏览器与 Node 共用
- `dist/vendor/`：按需加载的 HEIC 解码器及许可证
- `server.mjs`：仅监听 127.0.0.1 的本地静态服务器
- `tests/core.test.cjs`：核心格式测试

ICO、ZIP 编码使用原生 JavaScript。HEIC 支持使用 heic-to 1.6.5，许可证及源码链接见 `THIRD_PARTY_NOTICES.md`。
