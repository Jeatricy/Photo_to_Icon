## 独立解码验证

使用 Python Pillow 检查通过浏览器实际下载的文件：

- 多分辨率 ICO 包含且仅包含 32x32、48x48、256x256。
- 各个 ICO 帧左上角透明、中心不透明。
- PNG 精确为 256x256，并保留 0 / 128 / 255 三种 Alpha 值。
- 带底色及圆角的 PNG 左上角透明、背景为 #ffcc00，原图中心颜色正确。

使用 Python zipfile 检查 ZIP 的 CRC，无损解压出的中文文件名正确，内容与单独下载的 ICO 完全一致。
